# 学習モード

## 導入

1. `npm ci` と `npm run db:generate` を実行します。
2. `DATABASE_URL` が正しいDBを指していることを確認し、`npm run db:learning` を一度実行します。既存テーブルを変更・削除せず、学習用の4テーブルとインデックスだけを追加します。
3. `npm run build` でビルドして通常どおりデプロイします。ブラウザPythonの静的ファイルはビルド前に自動生成します。
4. ヘッダーの `Learn` → `コースを作成` から教材を登録します。作成権限は `problem_author` または `admin` です。

既存のR2環境変数を使用します。新しいバケット、CORS設定、VPSは不要です。公開教材のMarkdownは `learning/<versionId>/<itemId>.md` に保存し、読み取りは認可を確認したサーバー経由で行います。R2が未設定なら学習専用テーブル内にMarkdownを保存します。明示的なDB保存は `LEARNING_STORAGE=db` で指定できます。R2への保存に失敗した場合は、DB保存へ黙って切り替えず公開を失敗させます。

ジャッジ隔離の移設、Heroku課金・Config Vars、既存問題・提出データの変更はこの機能の導入に不要です。

## 教材の構成

- コース → 章 → 個別タブ（教材・確認クイズ・練習問題）。
- 章・タブの追加、削除、名前変更、並べ替え、必須／任意設定。
- 下書き保存と公開を分離。公開すると新しい不変の版を作成します。
- 公開範囲は全体公開、リンク限定、作成者・管理者のみ。リンク限定はゲストの一覧に出ません。
- 表示中のタブだけ本文を取得し、エディターを生成します。非表示の実行環境は停止・破棄します。
- タブ切り替えでコード・標準入力・クイズ回答・提出言語・直近の提出IDを復元します。コード下書き等はブラウザ保存で、別端末には同期しません。
- URLの `version` と `item` で公開版・タブを指定できます。戻る／進むにも対応します。

公開版ごとに進捗を保存します。新しい版の進捗は初期状態から始め、以前の版のURL・進捗は残します。同じコースが引き続き閲覧可能な場合に限り古い版も読めます。公開停止すると学習者は古い版も読めなくなります。現時点では個別ユーザーへの非公開コース招待と、版間の進捗自動移行は未実装です。

## Markdownとコードセル

以前の版に読了・合格・ACの進捗がある場合、コース一覧に「以前の版の進捗から再開」を表示します。プロフィールにも以前の版の進捗を残します。

GFMの表・箇条書き、数式 `$...$` / `$$...$$` に対応します。HTMLやMDXのJavaScriptは実行しません。

````markdown
## 入力を試す

次のコードを変更してください。

```python run id=greeting
name = input()
print(f"こんにちは、{name}さん")
```

ここに続きの説明を書けます。
````

- `run` がない普通のコードブロックは静的表示です。
- 実行言語は `python` と `javascript`。各実行欄には一意で安定した `id` が必須です。
- 作成画面の挿入ボタンで記法を生成できます。
- 各セルの標準入力初期値・コード編集可否を設定できます。
- `.md` ファイルの取り込みとライブプレビューに対応します。
- クイズ・練習問題の補足Markdownにもコードセルを入れられます。

## 試し実行の境界

Pythonは固定したPyodide 0.27.7（Python 3.12）のブラウザ実行です。パッケージに同梱された静的ファイルを自サイトから取得するので、実行時の外部CDNアクセスは不要です。このバージョンではopaque-originのclassic Workerを使用します。アップグレード時は実行と隔離のブラウザ検証をやり直してください。

実行環境は `sandbox="allow-scripts"` のiframe内のBlob Workerです。`allow-same-origin` は付けません。認証Cookie、localStorage、アプリのDOMや秘密情報を渡さず、CSPで通信先を公開されたPython実行用ディレクトリに限定します。そのディレクトリはAuth.js proxyから除外し、認証を伴う応答を返しません。メッセージの送信元・ランダムトークン・種類・長さを検証します。

- 実行ごとにWorkerとPython環境を新規作成。グローバル変数・仮想ファイルを次回に持ち越しません。
- 実行10秒、準備90秒、出力64 KiB（UTF-8）とメッセージ数の上限。停止・タブ離脱でiframe/Workerを破棄します。
- ブラウザのメモリに厳密な上限を設ける仕組みではありません。大量のメモリ確保や大量の子Worker生成に対する完全な資源隔離ではありません。
- 初回は約14 MBの実行用ファイルを取得します。ファイルはブラウザキャッシュで再利用しますが、実行環境は再利用しません。
- 標準ライブラリを中心としたPython教材用です。pip、外部通信、NumPy等の追加パッケージ自動取得には対応しません。
- JavaScriptはブラウザWorker用で、`console.log` / `console.error` / `input()` / `print()` を使えます。Node.jsの `require` / `fs` / `process` はありません。
- C++・Javaの教材内試し実行は未実装です。練習問題の正式提出では既存の4言語を使用できます。
- 実行結果は成績に使いません。教材の読了は自己申告、クイズ合格はサーバー採点、練習問題完了はサーバーが本人・対象問題・ACを検証して保存します。

サーバージャッジの隔離制約は従来どおりです。ブラウザの試し実行追加はサーバージャッジの隔離を改善するものではありません。

## クイズ・練習問題・進捗

クイズは単一選択式、1-30問、各2-8選択肢、合格率1-100%です。教材APIは正解・解説を返さず、回答送信後に採点結果と解説を返します。再採点には3秒の間隔が必要です。合格後の誤答で完了を取り消しません。

練習問題は既存の公開問題を関連付け、タブ内で問題文・サンプル・提出欄を表示します。提出結果を定期更新し、Test Resultsへのリンクを表示します。「ACを確認して完了にする」で進捗を保存します。過去ACを許可する設定もあります。非公開問題のアクセス権はコース経由では付与しません。

学習進捗は `LearningProgress` の本人／公開版／タブの複合キーで保存し、AppStateのスナップショットを変更しません。公開・編集はeditVersionによる楽観ロックで上書き競合を防止します。プロフィールから公開版の学習進捗を確認できます。

## ZIPの取り込み・書き出し

作成・編集画面で、現在の下書きをZIPダウンロードできます。取り込みとZIP生成はブラウザで行います。

```text
course.json
lessons/
  input.md
  output.md
  check.md
```

`course.json` は `formatVersion: 1` とコース設定、章、タブ、セルの設定、クイズの正解・解説、関連する問題IDを含みます。各タブの `markdownFile` は `lessons/<itemId>.md` です。ZIPは作成者用で、正解を含むため学習者に配布しないでください。問題本体やテストケースは含みません。別環境へ移す場合は関連付け先の問題を別途用意してください。

テンプレートを生成できます（既存ファイルは上書きしません）。

```powershell
npm run template:learning-zip
```

現在の上限：コース2 MiB、ZIP圧縮前後2 MiB、50章、合計200タブ、1章50タブ、各本文256 Ki文字、1本文20実行欄。画像添付アップロードは未実装です。画像はMarkdownの外部URLを使用してください。

## 検証

学習ページを含むサイトのUIは、ヘッダーの「日本語 / English」で切り替えられます。教材本文や作成者が登録した名前は自動翻訳しません。編集中の入力は言語変更でも保持します。学習ページの見出しは通常のページと同じ簡潔な形式で、実行欄にPython初回ダウンロードの説明は表示しません。詳細は [日英UIの仕様](i18n.md) を参照してください。

```powershell
npm run test:learning
npm run lint
npx tsc --noEmit
npm run build
```

DB統合テストは `LEARNING_TEST_DATABASE_URL` にローカルの専用DB `ojp_learning_test` を設定した場合のみ実行します。通常のDBや本番DBでは実行しないでください。

```powershell
$env:LEARNING_TEST_DATABASE_URL = 'postgresql://postgres:learning-test@127.0.0.1:15433/ojp_learning_test?schema=public'
npm run test:learning:integration
```
